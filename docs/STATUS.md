# Статус проекта

Дата актуализации: 29.08.2026.

## Цель

Перенести `numerologpro.ru` с Ghost на статический сайт из HTML, CSS, JavaScript и локальных ресурсов, опубликовать его через GitHub Pages и после полного QA подключить существующий домен.

Итоговый сайт представляет «Тихий Дом» как зонтичный бренд и предоставляет бесплатные точки входа в отдельные Telegram-боты продуктов.

## Текущий гейт

Финальный предрелизный baseline: `5ae69967647909f9d97d8d595a791a46f7b0139f` (`refactor: remove legacy product markup`).

Шесть CSS-файлов объединены в один `assets/css/site.css`; дубли шрифтов и общих правил удалены. Главная, `/about/`, КвантоКод, Mystic Oracle и ЭЛИОР прошли desktop/mobile browser QA после консолидации и последующих визуальных исправлений.

Из product pages удалены скрытые SEO-заголовки, legacy Article metadata и Schema.org, Telegram ref-workaround, дублирующий stylesheet preload и другие подтверждённые Ghost-хвосты. Воспроизводимый static-site integrity checker проходит.

Production cutover на GitHub Pages завершён. Custom domain `numerologpro.ru`, DNS apex, `www` и HTTPS работают; обязательные маршруты и ресурсы проверены. Пользовательский production QA пройден. Каталоги `migration-audit/` и локальная `.work/` удалены после переноса итоговых фактов в постоянную документацию.
