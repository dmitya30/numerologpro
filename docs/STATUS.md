# Статус проекта

Дата актуализации: 28.08.2026.

## Цель

Перенести `numerologpro.ru` с Ghost на статический сайт из HTML, CSS, JavaScript и локальных ресурсов, опубликовать его через GitHub Pages и после полного QA подключить существующий домен.

Итоговый сайт представляет «Тихий Дом» как зонтичный бренд и предоставляет бесплатные точки входа в отдельные Telegram-боты продуктов.

## Текущий гейт

Финальный предрелизный baseline: `5ae69967647909f9d97d8d595a791a46f7b0139f` (`refactor: remove legacy product markup`).

Шесть CSS-файлов объединены в один `assets/css/site.css`; дубли шрифтов и общих правил удалены. Главная, `/about/`, КвантоКод, Mystic Oracle и ЭЛИОР прошли desktop/mobile browser QA после консолидации и последующих визуальных исправлений.

Из product pages удалены скрытые SEO-заголовки, legacy Article metadata и Schema.org, Telegram ref-workaround, дублирующий stylesheet preload и другие подтверждённые Ghost-хвосты. Воспроизводимый static-site integrity checker проходит.

GitHub Pages custom domain `numerologpro.ru` настроен, корневой файл `CNAME` создан GitHub. Каталог `migration-audit/` удаляется из публикуемой ветки после переноса итоговых фактов в постоянную документацию. Текущий гейт - DNS cutover и production QA. DNS, VPS и Ghost пока не изменялись.

## Завершённый первичный аудит страниц

- Через системный `curl` получены HTML-снимки `/`, `/elyor/`, `/quantocode/`, `/oracle/` и `/about/`.

- Снимки и отчёт `audit.json` хранятся во временном игнорируемом каталоге `.work/source-audit/`.
- Проверены успешные HTTP-ответы, размеры снимков и их соответствие отчёту.
- Выполнен человеческий визуальный QA локальных снимков.
- Зафиксировано наличие коммерческих и Ghost-служебных маркеров, которые нельзя переносить автоматически.
- В репозитории находится воспроизводимый инструмент `scripts/audit-source.py`; временные снимки в Git не добавляются.
- Санитизированный manifest и человекочитаемая сводка исходных страниц подготовлены в отслеживаемом каталоге `migration-audit/`.
