# Временный контекст аудита и переноса

Этот каталог хранит проверяемый санитизированный контекст миграции, доступный через публичный GitHub-репозиторий.

## Назначение

- не зависеть только от локальной `.work/` и истории диалога;
- фиксировать фактические метаданные, публичные CTA и ресурсы исходного сайта;
- использовать manifest как входные данные для дальнейшего аудита и переноса;
- не восстанавливать факты по памяти после сжатия контекста.

## Файлы

- `source-pages.json` — машиночитаемый санитизированный отчёт;
- `source-pages.md` — человекочитаемая сводка того же отчёта.

## Что сюда не помещается

- сырые HTML-снимки без отдельной проверки;
- Ghost Content API keys;
- cookies, authorization headers, пароли, токены и SSH-данные;
- конфигурация VPS и приватного infra-репозитория;
- необработанные Code Injection и серверные конфигурации.

## Ограничение

Удаление каталога из текущей ветки не удаляет его из истории публичного Git. Перед GitHub Pages production-публикацией каталог должен быть удалён из публикуемой ветки, а итоговые необходимые факты перенесены в постоянную проектную документацию.
